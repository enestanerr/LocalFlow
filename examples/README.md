# Recipe examples

Import one of these JSON files with **Import** in LocalFlow. They contain settings only; bring your own images or use the generated samples.

| Recipe                                       | Result                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| [Web-ready images](web-ready.json)           | Fit within 1600 × 1600, encode WebP at quality 80, add a sequence number |
| [Square product shots](square-products.json) | Center square crop, fit within 1200 × 1200, export JPEG on white         |
| [Compact previews](compact-previews.json)    | Fit within 640 × 640, encode WebP at quality 75                          |

Recipes use schema version 1. Adjust quality and dimensions for your actual inputs; a smaller file size is not guaranteed for every source image.
